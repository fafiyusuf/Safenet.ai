# 🛡️ SafeNet.ai

> **AI-Powered Evidence Collection Platform for Technology-Facilitated Gender-Based Violence (TFGBV) in Ethiopia**

![Status](https://img.shields.io/badge/status-Live-brightgreen) ![Next.js](https://img.shields.io/badge/next.js-16-black) ![TypeScript](https://img.shields.io/badge/typescript-5.3-blue)

**🌐 LIVE:** Deployed on Vercel + Render | December 2025

---

## 🚨 The Problem

**87% of Ethiopian women experience online harassment** with no accessible tools to:
- Collect digital evidence (all platforms English-only)
- Get immediate risk assessment
- Access legal documentation for Ethiopian courts
- Find verified support organizations

---

## 💡 Our Solution

Ethiopia's first **bilingual (English/Amharic)** TFGBV platform with AI-powered evidence collection.

**What it does:**
- 📸 Analyzes abuse screenshots with Google Gemini AI
- 📄 Generates court-ready evidence PDFs + police complaint forms
- 🆘 Connects to emergency hotlines (7711, 6388, 8044)
- 🗺️ Lists 7 verified Ethiopian organizations (AWSAD, EWLA, ELiDA, etc.)
- 🔒 100% anonymous, auto-deletes after 30 days

**Two Modes:**
1. **Evidence Mode:** Upload screenshots → AI analysis → Legal documents
2. **Conversational Mode:** Paste text → Get counseling + safety advice

---

## ✨ Key Features

**For Survivors:**
- AI severity scoring (0-100) + threat classification
- Tamper-proof PDFs with timestamps & crypto hashing
- Pre-formatted Ethiopian Federal Police complaint forms
- One-click emergency hotline dialing
- Complete anonymity (no login/tracking)

**For Organizations:**
- Admin dashboard with real-time statistics
- Pattern tracking by platform (Telegram, Facebook, Instagram, etc.)

## 🏗️ Tech Stack

**Frontend:** Next.js 16 + React + TypeScript  
**Backend:** Express.js + Node.js  
**Database:** Neon PostgreSQL  
**AI:** Google Gemini 2.5 + 50+ keyword fallback  
**OCR:** Tesseract.js (English + Amharic)  
**Hosting:** Vercel + Render

## 🛠️ Quick Start

```bash
# Backend
cd Backend-Express && npm install
# Add DATABASE_URL, GEMINI_API_KEY to .env
npm run dev

# Frontend
cd Frontend && pnpm install
# Add NEXT_PUBLIC_API_URL to .env.local
pnpm dev
```
